## 一、已完成的核心改進總結

1. **對位判定與視角方向統一**
   - 修正 `rotToYawRad(rot) = -(rot * Math.PI) / 180` 與 `rawRotPoint` 的旋轉符號一致，確保 `L3`、`slope1x1`、`slope1x2` 等不對稱積木在 3D 物理體、鬼影預覽、桌面線框與 2D 說明書中的朝向完全吻合。
   - 完成判定採用「相對位置＋相對旋轉群組對齊」，即使組裝在拼圖墊稍微偏移的位置，只要相對結構正確即可完成。
2. **拆磚演算法重構（含大型底板 `2x3` / `2x4` / `4x4` 支援）**
   - 在 `src/engine/brickPlanner.ts` 納入 `4x4`、`2x4`、`2x3`、`1x4`、`2x2`、`1x3`、`L3`、`1x2`、`1x1`。
   - 連通區域 `<= 14` 格直接運行精確最佳化搜尋，優先減少總磚數與孤立單格；大型區域則以防孤立前瞻貪心填放；支援 `largePlateLayers` 針對餐盤／底座層自動使用大板減少瑣碎拼塊。
3. **斜坡、多材質、特殊支架與實時 3D 動物整理**
   - `brickGeometry.ts` 新增倒角斜坡幾何體；`BrickWorkshopEngine.ts` 支援 `plastic` / `matte` / `metallic` / `glass` 四種 PBR 物理材質；《踩到香蕉皮飛起來》改用內建式一體成型透明壓克力斜角支架。
   - `roomDiorama.ts` 新增即時 3D 乳牛走近書桌與貓頭鷹飛入盤旋整理動畫（無黑屏遮擋），《軟萌長耳白兔》已修正臉部前突磚塊遮擋眼睛問題，無盡模式開局改為桌面淨空並具備 `orderSandboxBatch` 批次訂購引擎接口。
4. **模型陣容調整**
   - 移除「打翻的咖啡漬」，改為《窗邊晨露小草》（霧面培養土、斜面草葉、雛菊與玻璃晨露水珠）。
   - 重製《軟萌長耳白兔》為完整 13 層 Q 版坐姿長耳白兔（前伸雙爪、圓尾、紅蘿蔔配件、晴空藍項圈、腮紅粉鼻與斜角耳尖）。

## 三、CrazyGames 上架、存檔容量與廣告變現建議

### 1. 1MB 雲端存檔上限評估
- **目前佔用**：單筆 `SavedBuildState`（約 80～150 顆積木座標與姿態）序列化後約 **12KB～28KB**；3 格成品櫃紀錄合計約 **1KB**，加上自訂沙盒狀態，總計遠低於 CrazyGames 單使用者 **1MB** 配額（通常佔用率 `< 10%`）。
- **建議**：`src/services/storage.ts` 與主選單已顯示本地容量監控，正式對接 CrazyGames Data Module (`window.CrazyGames.SDK.data`) 時，建議只儲存精簡座標紀錄，避免把龐大 Three.js/canvas 截圖 Base64 塞進存檔字串。

### 2. 廣告位與節奏設計（不破壞療癒沉浸感）
本作屬於慢節奏、療癒型的桌面拼砌體驗，**切忌打斷手上的拼砌操作**：
- **插頁廣告 (`midgame`) 時機**：
  1. **開箱前或整組作品完成並點擊「看成品櫃」時**觸發一次（天然轉場節點，接受度最高）。
  2. **連續遊玩提醒休息（Break Reminder）**：可設定每累計遊玩 **18～25 分鐘**，且剛好完成某個「步驟／區塊」並放開手指處於閒置狀態時，彈出溫和休息提示（「桌前專注了 20 分鐘，讓眼睛看一眼窗外風景吧」），並可搭配輕量休息過場或切換書桌時間，避免強制中斷正在拖曳的積木。
- **激勵影片 (`rewarded`) 實用價值點**：
  1. **「自動幫我分類現有深籃零件到 3 小盤」**：當地獄深籃混亂不堪時，看一段短廣告請動物幫忙依顏色快速分盤（平常動物只幫忙集中不分類，形成清晰差異！）。
  2. **「透視／高亮整層所需所有積木並直接跳到盤子頂層」**：比免費的「找本步零件」更強的「本層一鍵撈出」，適合卡關找小零件的時候。
  3. **解鎖進階限定模型或高級金屬／夜光材質色票**（沙盒模式）。

## 四、Roblox 延伸改編可行性評估（Build & Display Tycoon）

玩家構想的玩法迴圈：**「在自己房子門前擺放展示檯 → 完成的積木放在檯面上每秒產生收益 → 用收益解鎖更大底板／新材料（如金屬、玻璃、斜坡磚）或更大組圖紙 → 自創積木作品也能上架擺攤賺錢」**，這個機制 **非常適合 Roblox**！

### 為什麼這套機制在 Roblox 很有潛力？
1. **明確的視覺炫耀感（Social Flex）**：Roblox 玩家非常喜歡走到別人房子前參觀「別人的門前展示檯擺了什麼超帥大型積木」，比單純擺機器人產錢的大亨遊戲更有創作識別度。
2. **「組裝手感 × 放置經濟」雙核心**：組裝大模型雖然花時間，但因為擺到屋前檯子上能**長期持續產錢／加乘（每秒金幣 × 稀有度 × 材質倍率）**，玩家會有強烈動力把作品好好拼完。
3. **UGC 創作自然融入**：把「自由創作匯出圖紙（類似 `BW1` 體素規格）」變成玩家可以販售藍圖或在展示店擺攤的機制，能把生命週期拉得很長。

### 若轉入 Roblox (Luau) 需注意的實作差異
- Roblox 原生支援 `BasePart` / `Model` / `WeldConstraint`，不需要自行實作 Rapier 物理，但零件過多時（如 300 顆以上擺滿整個大亨村莊）必須針對**遠處鄰居家的展示模型進行 Mesh 合併或 LOD 簡化**，以免手機端 Roblox 掉幀。
- 建議將 **「小盤子整理」改為快捷熱鍵欄 / 桌面 UI 拾取，主桌面保留「凸點對位喀嗒拼砌＋橘色拆件器」**，以符合 Roblox 第一／第三人稱鍵鼠與虛擬搖桿習慣。
