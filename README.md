# 積木工坊（Brick Workshop 3D）

以 **React + TypeScript + Three.js + Rapier3D** 打造的擬真桌面 3D 積木拼砌模擬器。從拆開商品彩繪紙箱、打開依顏色與尺寸分裝的小袋、在三個可命名小盤與「地獄深籃」之間整理零件，到對齊凸點「喀嗒」壓緊、透過組裝說明書旋轉檢視步驟並展示成品，完整重現實體積木開箱與組裝手感。

---

## 目前已實作核心功能

### 1. 積木引擎與物理拼砌體驗
- **11 種積木形狀與 4 向朝向**：支援 `1x1`、`1x2`、`1x3`、`1x4`、`2x2`、`2x3`、`2x4`、`4x4`（大底板）、`L3`（三格轉角 L 形）、`slope1x1`（1×1 斜坡）、`slope1x2`（1×2 斜坡），所有不對稱件皆支援 `0° / 90° / 180° / 270°` 精準旋轉與凸點判定。
- **4 種物理材質表現**：`plastic`（亮面塑膠）、`matte`（霧面磨砂，如泥土／岩塊／毛髮／草地）、`metallic`（金屬高光，如金獎盃／銀牌／太空人金面罩）、`glass`（透明玻璃與晨露／窗玻璃／白煙）。
- **智慧連通填磚拆解 (`brickPlanner.ts`)**：
  - 優先維持連續 4 格完整條（避免 4 格誤拆成 `3+1`）與 `L3` 轉角／`2x2` 結構；針對標記 `largePlateLayers` / `allowLargePlates` 的層（如大型餐盤底層），會優先自動使用 `4x4`、`2x4`、`2x3` 大板。
  - 連通小區間（≤14 格）採用精確最小磚數演算法，大面積區塊採防孤立前瞻配對。
- **物理模擬與雙重回饋**：
  - Rapier3D 剛體碰撞＋擬真手部阻尼拖曳、第二指輕點或按 `R` 旋轉、點放（Tap-to-Place）與拖曳（Drag）雙操控模式切換。
  - **橘色拆件器 (`X`)** 可精準撬起已壓緊的單顆積木；**手指翻找 (`F`)** 可直接撥動籃中壓在底層的零件；支援 `Ctrl+Z` 多步復原。
  - 支援 **Web Audio 合成積木卡扣音效** 與 **手機震動觸覺回饋 (Haptics)**。

### 2. 書桌房間場景、開箱流程與盤籃機制
- **商品彩繪積木箱與真實分裝小袋**：主桌面可點擊印有該模型等角彩繪的商品紙箱開箱，取出依顏色／尺寸分類且緊密排列的分裝小袋，開袋後即時倒入指定盤／籃，倒空後袋子消失。
- **3 個可命名小盤 ＋ 1 個大容量地獄深籃**：
  - 小盤超出建議容量時會溢出到桌面；玩家可手動互倒（從深籃撈 10 顆進小盤，或整盤倒回深籃）。
- **可開關窗簾書桌與實時 3D 動物整理動畫**：
  - 桌面正前方設有細緻窗外田園／夜空場景，可切換窗簾開關（影響室內明暗）與白天／夜晚窗景（白天草地黑白乳牛／夜晚樹梢貓頭鷹）。
  - 散落桌面積木過多或手動呼叫整理時，會直接播放 **3D 乳牛跨窗台走近桌面** 或 **3D 貓頭鷹展翅飛進桌面上空盤旋** 的即時動畫並搭配非遮罩浮動字幕（不再使用黑屏遮擋）。

### 3. 3D 說明書、無盡模式與分享機制
- **360° 可拖曳旋轉 3D 步驟示意圖**：支援手動拖曳旋轉、左轉/右轉 45°、一鍵正面視角，與實時投影精準一致（支援 `L3`、`slope1x1`、`slope1x2` 與大型底板渲染）。
- **內建式透明斜角展示支架（《踩到香蕉皮飛起來》）**：左側為人行道與香蕉皮並內建壓克力斜角支架，右側拼好驚嚇滑倒小人後點擊支架或按鈕，即可把整尊小人以 `-38°` 後仰斜角度騰空掛上支架展示。
- **分區子組裝台**：大型模型可先在右側子組裝台單獨拼好頭部或零件模組，再整塊拖曳合體到主體。
- **無盡自由創作模式**：開局桌面淨空，由玩家選擇 11 種形狀、色盤與材質即時訂購倒入盤中，支援 `orderSandboxBatch` 批次下單與 `BW1:` 分享碼匯出。

## 開發與建置指令

```bash
npm install
npm run dev      # 啟動本機開發伺服器 (Port 3000)
npm run build    # 產出正式版 dist/
npm run lint     # 型別檢查 (tsc --noEmit)
```
